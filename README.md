## ☁️ AWS Deployment

The website was deployed using Amazon S3 Static Website Hosting.

### Deployment Process

1. Created an Amazon S3 bucket
2. Uploaded website files
3. Enabled Static Website Hosting
4. Configured bucket permissions
5. Added a bucket policy for website access
6. Tested the live S3 website endpoint
